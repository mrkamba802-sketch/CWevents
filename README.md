# CWevents

Автоматический ивент «Воздушный конвой» для Paper 1.21.4+ и Java 21.

## Возможности

- Автоматический запуск по интервалу и настраиваемому шансу.
- Рандомная или фиксированная точка появления корабля.
- Сгенерированный воздушный корабль с сундуком.
- Несколько волн охраны и финальный босс.
- Сундук разблокируется только после победы над боссом.
- Первый игрок, открывший сундук, становится владельцем награды.
- Награды задаются в config.yml: предметы, вес выпадения, диапазон количества, консольные команды победителю и участникам.
- Защита зоны: запрет ломания/установки блоков, взаимодействий, вёдер, взрывов, огня, поршней, команд и телепортации.
- Игровой PvP между игроками не отключается.
- Временные блоки и мобы очищаются при завершении ивента и при штатном выключении сервера.

## Установка

1. Установите Paper 1.21.4+ и Java 21.
2. Скачайте CWevents.jar из GitHub Actions artifact.
3. Поместите JAR в plugins/ и перезапустите сервер.
4. Настройте plugins/CWevents/config.yml.
5. Выполните /cwevents reload.

## Команды

- /cwevents start — принудительно запустить событие.
- /cwevents stop — остановить событие и очистить корабль.
- /cwevents status — статус события.
- /cwevents reload — перезагрузить конфигурацию.
- /cwevents setlocation — задать фиксированную точку по текущему местоположению администратора (корабль строится выше).

Все команды управления требуют cwevents.admin.

## Сборка

Выполните mvn clean package. Результат: target/CWevents.jar.

## Настройка наград

Примеры команд выполняются консолью:
- eco give %player% 5000
- give %player% diamond 8

Экономические команды требуют установленного плагина экономики. CWevents не зависит от Vault или конкретного economy-плагина.
